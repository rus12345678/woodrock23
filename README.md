# WoodRock — Ландшафтная архитектура и комплектация

Полноценный адаптивный веб-сайт премиального бренда ландшафтного дизайна, архитектурных материалов мощения, всепогодной уличной мебели и оборудования для загородных участков.

Дизайн выполнен по визуальным принципам **DJI**:
- Чистая, спокойная эстетика с приоритетом крупных фотографий и рендеров
- Светлый фон со сбалансированными серыми подложками
- Фирменная горизонтальная лента категорий с плавным скроллом
- Выразительная типографика и контрастные интерактивные элементы
- Полная адаптивность под мобильные телефоны, планшеты и десктоп
- Интерактивные точки (Hotspots) на общих видах пространств
- **Двусторонняя строгая связь** между товарами каталога и готовыми решениями.

## 🚀 Быстрый запуск

### 1. Установка зависимостей
```bash
cd woodrock
npm install
```

### 2. Запуск локального сервера разработки
```bash
npm run dev
```
После запуска откройте в браузере адрес: `http://localhost:5173`

### 3. Сборка для продакшена и проверка
```bash
npm run build
npm run preview
```

## 🧭 Двусторонняя навигация («Проектирование → Комплектация → Готовые решения»)

В проекте реализована строгая взаимосвязь данных:
- Сущность **Product** (`src/data/products.ts`)
- Сущность **Solution** (`src/data/solutions.ts`)
- Связи разрешаются автоматически через `src/utils/relations.ts`:

### 🔄 Сценарий 1: Товар → Готовое решение
1. Пользователь переходит в **«Каталог»** (`/catalog`) или кликает фильтр **«Материалы»**.
2. Открывает карточку **«Архитектурная плита Nordic Stone 800×800»** (`/catalog/mat-architectural-plate-nordic`).
3. В карточке видит спецификации и заметную кнопку **«Посмотреть в готовом решении»** (или блок внизу страницы со списком зон).
4. Нажимает и переходит в готовое решение (например, **«Зона бассейна Nordic Horizon»** или **«Патио с кострищем»**), где применена именно эта плита.
5. Изучает окружение, полный состав сопутствующих товаров и может запросить расчет.

### 🔄 Сценарий 2: Готовое решение → Товар
1. Пользователь открывает раздел **«Готовые решения»** (`/solutions`) и выбирает **«Зону бассейна Nordic Horizon»** (`/solutions/sol-pool-minimal`).
2. Видит крупный панорамный рендер с **интерактивными точками (Hotspots)**.
3. Нажимает на точку у борта или на шезлонг — всплывает карточка с фото и описанием элемента.
4. Нажав кнопку **«В карточку товара»**, пользователь переходит на страницу товара (`/catalog/mat-coping-pool-stone` или `/catalog/furn-chaise-longue-aero`).
5. В любой момент может вернуться к исходному пространству по хлебным крошкам или блоку готовых решений.

## 📋 Система заявок и честный Демо-режим

Заявки классифицируются по трем контекстам:
1. **На проектирование** (включает поле площади участка, пожелания)
2. **На отдельный товар** (автоматически прикрепляет ID и название товара)
3. **На комплектацию решения** (автоматически прикрепляет ID и название пространства)

### Прозрачность демо-режима:
- До подключения реального бэкенда сайт **не показывает ложных уведомлений** вроде «Менеджер уже выехал».
- Пользователь видит честное сообщение: *«Заявка сформирована в демонстрационном режиме и сохранена локально»*.
- Все отправленные тестовые заявки сохраняются в `localStorage` и отображаются на странице **«Контакты»** в блоке **«Журнал обращений»**.

## ⚙️ Список мест для настройки и замены данных

| Что заменить | Где находится файл | Описание |
|---|---|---|
| **Контакты компании** (телефон, email, адрес, график, ссылки на Telegram/WhatsApp) | `src/config/siteConfig.ts` | Блок `contacts` |
| **Подключение отправки заявок** (вебхук Telegram, CRM, API) | `src/config/siteConfig.ts` | Параметры `inquirySettings.isDemoMode` и `inquirySettings.apiEndpoint` |
| **Каталог товаров** (материалы, мебель, оборудование, характеристики, фото) | `src/data/products.ts` | Массив `productsData` |
| **Готовые решения** (бассейны, барбекю, патио, террасы, дорожки, координаты Hotspots) | `src/data/solutions.ts` | Массив `solutionsData` |
| **Этапы проектирования и регламент** | `src/data/process.ts` | Массивы `processSteps` и `designTiers` |
| **Цвета и дизайн-токены** | `tailwind.config.js` | Объект `theme.extend.colors` |
| **Иконка и метатеги** | `index.html` и `public/favicon.svg` | Мета-заголовки, описание сайта |

### Пример подключения реального обработчика заявок:
В файле `src/config/siteConfig.ts`:
```ts
export const siteConfig = {
  // ...
  inquirySettings: {
    isDemoMode: false, // выключаем демо-режим
    apiEndpoint: 'https://api.yourdomain.ru/v1/leads', // ваш вебхук или адрес API
  },
};
```
